# Mobile Sales Interactive Power BI Dashboard

An interactive Power BI dashboard designed to analyze and visualize mobile sales data. This project provides comprehensive insights into sales performance, transactions, and historical comparisons.

## 📊 Project Overview
This repository contains a complete Power BI project (`MS_Dashboard -.pbix`) and the accompanying dataset (`Mobile Sales Data.xlsx`). It demonstrates how to build interactive reports to track key business metrics over various time periods.

### Key Reports Included:
1. **Main Dashboard**: High-level overview of mobile sales, quantities, and transaction averages.
2. **MTD (Month-to-Date) Report**: Detailed breakdown of sales performance for the current month.
3. **SPLY (Same Period Last Year) Report**: Year-over-year comparison to analyze growth and trends.

## 📁 Repository Contents
* **`MS_Dashboard -.pbix`**: The main Power BI project file containing the data model, DAX measures, and visuals.
* **`Mobile Sales Data.xlsx`**: The raw dataset used for analysis.
* **Images & Icons**: Various assets used for the dashboard UI design (e.g., `Background.jpg`, `Filter.png`, `Average.png`, `Transactions.png`).
* **Previews**: High-resolution screenshots of the reports.

## 🚀 How to Use
1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/Abhijayshah1/Power_BI_Dashboard.git
   ```
2. Download and install **Power BI Desktop** (if not already installed).
3. Open the `MS_Dashboard -.pbix` file.
4. Interact with the filters and visualizations to explore the data.
